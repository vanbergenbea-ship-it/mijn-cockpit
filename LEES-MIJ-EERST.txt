MIJN COCKPIT V6 – UPDATE VIA GITHUB

1. Maak eerst in Mijn cockpit > Instellingen > Exporteren een back-up.
2. Open https://github.com/vanbergenbea-ship-it/mijn-cockpit
3. Vervang in de ROOT van de main-branch de 6 bestanden: index.html, ochtendroutine.html, sw.js, manifest.webmanifest, icon-192.png en icon-512.png. Je kunt dit via Add file > Upload files doen. Bevestig met Commit changes.
4. Wacht tot GitHub Pages klaar is. Open de bestaande URL. Vernieuw de pagina indien nodig.
5. Test aanmelden, afmelden, opnieuw aanmelden en synchronisatie op beide toestellen.
6. Controleer daarna of Chrome op Samsung 'Installeren' aanbiedt. Dit is afhankelijk van browser en apparaat en kan niet gegarandeerd worden.

Dezelfde Supabase-database en dezelfde URL blijven in gebruik.
WAARSCHUWING: werk niet met vertrouwelijke werkgegevens voordat de live website en accountisolatie daadwerkelijk getest zijn.
